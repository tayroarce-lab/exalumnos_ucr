Refactorización integral: limpieza de mocks, visualización de matches y flujo de conexiones

- Eliminación completa de datos de prueba y mocks en perfiles y componentes (LinkedInProfileClient, StudentProfile).
- Se conectó la API del admin dashboard directamente a las tablas reales (donaciones, users, carrera_campus).
- Corrección visual en Directorio: El porcentaje de match (TarjetaEstudiante) ahora siempre se muestra visible usando los datos en tiempo real de Supabase.
- Mejora en la pantalla de Mentorías y Mis Conexiones (/mis-matches): Se omitieron los matches generados por el sistema ("sugeridos"). Ahora solo verás a estudiantes con los que activamente has conectado ("contactado" o "activo").
- Corrección del flujo de "Ofrecer apoyo" para crear y notificar el match de forma inmediata sin dejarlos como "sugeridos".
- Se habilitó la edición del campo "Empresa" en el formulario de publicación de empleos y se añadió la validación requerida.
- Limpieza de archivos de prueba antiguos o sin uso (loginMariel, test-chat, MockChatDrawer).
- Se agregó el esquema de la base de datos (schema_actual.sql) para referencia del modelo de datos real.
